# UMSI Engaged Learning Office – Tablet/Desktop version

This branch builds on the mobile-first site from Deliverable #2. The existing HTML pages, mobile navigation, content, and images are kept in place; the main additions are larger-screen layout refinements and a custom 404 page.

## Pages
- `index.html` – Home
- `prep.html` – Preparing for your experience
- `starting.html` – Starting your experience
- `during.html` – During your experience
- `404.html` – Helpful page for a missing URL

## Responsive approach
The original small-screen styles remain the base. Tablet rules start at 600px and desktop rules start at 900px, with an extra-wide adjustment at 1200px. The layouts use the existing Michigan Blue and Maize colors, a centered content width, flexible navigation, and responsive grids. Images keep their existing responsive `srcset` values.

## Accessibility checks to complete
Before submitting, open every published page at mobile, tablet, and desktop widths. Test keyboard navigation and the mobile menu, then run each page through WAVE and axe. Check the published URL for the 404 page as well. Save screenshots of the results with the page URL visible for the deliverable appendix.

The source files have not been represented as passing WAVE or axe by this README; record the actual results after testing the deployed site.
